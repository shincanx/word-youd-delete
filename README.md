Entry for the [make.fun bounty "The Word You'd Delete From the Dictionary"](https://make.fun/bounty/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2) — one word to erase from the dictionary forever. My word is **irregardless**: a double-negative mistake that bullied its way into the dictionary, where it now sits legitimised despite meaning exactly what "regardless" already means. Deleting it is the dictionary correcting its own mistake — and nothing is lost, because "regardless" was doing the job all along.

## Run

```sh
python3 main.py
```

Writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no dependencies, deterministic.
